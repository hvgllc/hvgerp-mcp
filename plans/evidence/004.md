## Regression đỏ rồi xanh

Lệnh dùng cho từng lần kiểm trọng tâm:

```bash
deno test --config deno.nojsr.json --sloppy-imports --frozen --allow-all src/api/frappe-client_test.ts
```

1. Fixture dùng AbortSignal của request thật được truyền vào fetch giả. Body giữ
   mở đến khi signal abort; watchdog 1000 ms làm test đỏ thay vì treo suite.
   Cleanup cuối test nhả stream, gỡ listener và chờ request kết thúc.
2. Trước sửa implementation: exit 1, **43 passed, 12 failed**. Tám ca body
   timeout báo `Request did not time out before body release`; bốn ca stream lỗi
   báo nhận TypeError thay vì FrappeAPIError. Tám ca timeout trước headers đã
   đạt. Không có lỗi import hoặc sanitizer.
3. Sau đưa fetch, body và parse vào cùng try/catch/finally: **55 passed, 0
   failed**. Thêm năm control HTTP/body/timer, chuyển lỗi stream sang tác vụ
   timer sau headers: lần cuối **60 passed, 0 failed**, gồm trong full suite.

Ma trận: headers/body x retries 0/1 x GET/POST/PUT/multipart. Mỗi ca xác nhận
status 408, mọi signal thực sự aborted và số request: GET là retries + 1, thao
tác ghi luôn một lần. Lỗi stream status 0 được retry chỉ với GET. Các ca HTTP
200/403/503/502/500 giữ status, body JSON hoặc text/malformed JSON và
Retry-After. Control đợi quá timeout sau body hoàn tất xác nhận signal không bị
abort muộn. Sanitizer mặc định được giữ nguyên, không bỏ qua kiểm resource hoặc
timer.

## Implementation

- Timer tồn tại đến finally sau đọc body, parse hoặc nhánh lỗi.
- AbortError thành FrappeAPIError 408; lỗi network/body thành status 0.
- FrappeAPIError đã phân tích HTTP được throw nguyên trạng, không mất status,
  body hay Retry-After.
- Không đổi retries, backoff, retryMethods, schema hoặc dependency.
