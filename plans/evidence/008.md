## Bước 1: kiểm chứng lỗi trước khi sửa

Đưa nguyên thuật toán CSV cũ vào helper thuần có module thật: header `join`,
cell qua cách định dạng hiển thị cũ, quote chỉ comma/quote, nối bằng LF. Việc
tách tạm thời giữ cách định dạng số `toLocaleString("en-US")` và null/boolean
cũ; không phải stub hay lỗi module thiếu. Chạy 12 test mới:

```sh
deno test --config deno.nojsr.json --sloppy-imports --frozen --allow-all src/ui/shared/csv_test.ts
```

Kết quả red: exit 1, `1 passed | 11 failed`. Các assertion thất bại đúng lỗi:
header và cell multiline không escape; không bảo vệ formula/control prefix; số
bị phân nhóm và làm tròn; NaN/Infinity không bị từ chối; null/boolean dùng chuỗi
hiển thị; LF thay CRLF; dữ liệu fixture thành nhiều hàng sai cấu trúc. Test lỗi
JSON stringify đã đạt ở baseline vì lỗi được truyền nguyên từ trước.

## Giới hạn

định báo trailing whitespace tại ba byte CR trong separator CRLF của `008.csv`.

khai báo đúng kiểu kết thúc dòng chạy thành công:

```sh
git -c core.whitespace=blank-at-eol,blank-at-eof,space-before-tab,cr-at-eol diff --cached --check
```

Cấu hình chỉ áp dụng cho lệnh này, không sửa Git config lâu dài hoặc bỏ kiểm
whitespace trong source. Format toàn worktree sau thêm evidence: exit 0, 226
